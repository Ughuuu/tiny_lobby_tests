# Blazium Lobby Server

This is the C++ implementation of the Blazium Web Server. It uses [uWebSockets](https://github.com/uNetworking/uWebSockets/tree/master)

## Requirements

- Run `install.sh`

1. MacOS

```sh
./install-macos.sh
```

2. Linux

```sh
./install-linux.sh
```

3. Windows

```sh
./install-windows.bat
```

## How to build

Run `build.sh` and then run `build/lobby_server`.
