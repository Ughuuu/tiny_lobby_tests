# Install

How to install it locally

## Requirements

- clang version 16.0.0
- cmake version 3.30.5
- Run `install.sh`

## How to build

1. MacOS

```sh
./bash/install-macos.sh
```

2. Linux

```sh
./bash/install-linux.sh
```

3. Windows

```sh
./bash/install-windows.bat
```

Run `./bash/build.sh` and then run `build/tiny_lobby`.

## Lint

Run `./bash/format.sh`.
